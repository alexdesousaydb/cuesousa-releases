# CueSousa

Instaladores de CueSousa. Descarga la última versión en [Releases](https://github.com/alexdesousaydb/cuesousa-releases/releases/latest):

- **Mac** (Apple Silicon): el archivo `.dmg`. La primera vez, si macOS avisa, usa «Abrir igualmente» en Ajustes › Privacidad y seguridad.
- **Windows** (64 bits): el archivo `.exe`. Si sale «Windows protegió su PC», pulsa «Más información» › «Ejecutar de todas formas». Después se actualiza sola.
